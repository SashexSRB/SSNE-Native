SSNE-Native (Serious Sam: Next Encounter Native) - changes since the first public release of Silly ReEncounter
=========================================================

After updating, open the launcher and choose "Update Game" once: the game is rebuilt on your PC with the new
engine (a few minutes, nothing is downloaded except, once, the new compiler - see "Compatibility").

SSNE-NATIVE 1.2.1
  - Fix (HUD at the screen edges): an ammo count of 1000 or more (e.g. picking up bullets at 999) moved the ammo
    number inwards, away from the weapon's ammo icon, until the weapon was selected again.

SSNE-NATIVE 1.2
  - New name: Serious Sam: Next Encounter Native (SSNE-Native). The launcher is now SSNE-Native (.exe) and the game
    SSNE-Native-Game (.exe); the files under the old names are removed once the game is rebuilt. Game data, saves,
    save states and settings stay as they are.
  - Automatic updates: when it starts, the launcher checks GitHub for a newer version and offers to install it. It
    downloads the new version, installs it in its folder, restarts, and rebuilds the game if the update brings a new
    engine. "Skip This Version" ignores a release; check_updates=0 in launcher.ini turns the check off.
  - The launcher's lettering uses Boink LET, the font of the game's menus, when it is installed on the PC (it isn't
    included: it's a commercial font), in the colors of the Serious Sam logo.
  Coming from an earlier version: download 1.2 once yourself (older launchers can't update themselves), copy its
  files into your folder, start SSNE-Native and choose Update Game. From then on updates install themselves.

SSNE-NATIVE 1.1.3
  - Fix (HUD at the screen edges): picking up armor or another item could move the health and armor display to the
    middle of the screen while the pickup message ("Armor +100") was shown.

SSNE-NATIVE 1.1.2
  - Fix (HUD at the screen edges): when a hint flew in, the health display could jump to the middle of the screen
    and text shadows could be left behind; text now always stays centered, and only the HUD's corner pieces (health,
    ammo, the NETRICSA envelope) and the weapon bar move out to the edges.
  - Fix (HUD at the screen edges): weapon icons of the weapon wheel (hold Q) could be drawn outside their slots; the
    wheel stays centered as a whole.

SSNE-NATIVE 1.1.1
  - Fix: with the HUD at the screen edges (widescreen), on-screen text such as hints, pickup messages and the
    combo counter could be split apart where it crossed from the middle of the screen to a side. Text and the
    pieces drawn with it now move as a whole.

SSNE-NATIVE 1.1
  Performance: about two and a half times the frame rate where the CPU is the limit (high frame rate limits,
  weaker CPUs, levels with a lot of geometry), and less GPU time per frame. Measured with the frame limit off on
  an i7-1360P laptop (16:9, internal resolution 1x; at higher resolutions the GPU is usually the limit): Arena
  gameplay 190 -> 448 fps, "Touts at the Colosseum" 57 -> 143 fps.
  - The game's graphics commands are processed on their own CPU thread, in parallel with the game, like the
    console's GPU (settings.ini: gx_thread = 0 restores the previous single-thread processing).
  - Texture coordinates and lighting are computed on the GPU (in the vertex shader) instead of the CPU; the result
    is the same image (settings.ini: gpu_vertex = 0 computes them on the CPU as before).
  - Faster vertex processing and draw recording on the CPU.
  - Full-screen layers lying on a clip plane (sky, the distortion effect, the HUD) keep the GPU's early depth
    test: 3-10% less GPU time per frame, same image.
  - The prebuilt engine in the build kit is compiled with profile-guided optimization.
  - Native resolution (F12 > Graphics > Internal resolution > Native): the game is rendered at exactly the size
    it's shown at, e.g. 1920x1080 in widescreen gameplay on a 1080p screen (1440x1080 for the 4:3 menus), instead of
    a multiple of 640x448 that has to be scaled to the screen.
  - Widescreen HUD: health, ammo and the weapon bar sit at the edges of the screen instead of in the middle 4:3 area
    (F12 > Graphics > HUD at the screen edges).
  - Widescreen: the pause menu, NETRICSA and mission briefings stay 4:3 like the other menus (NETRICSA's weapon
    model was out of place in widescreen), and 4:3 screens show a blurred copy of the picture at the sides instead
    of black bars (F12 > Graphics > Fill the sides of 4:3 screens).
  - Fix: the number key 5 picks the rocket launcher first, then the grenade launcher (it was the other way round).
  - Fix: with an uncapped frame rate, loading could make the game report "System looks hung" in its log.

SSNE-NATIVE 1.0 (github.com/SashexSRB/SSNE-Native)
  - Linux version: native launcher and game, built on your PC with the system's compiler (see README-Linux.txt).
  - Fix: the jeep (Via Aurelia and other levels) stopped steering and accelerating after a while, and jolted
    while driving, when the frame limit was above 60 fps. Its physics only work at the original frame rate, so
    the game now runs at 60 fps while you drive any vehicle (jeep, combine harvester); on foot your limit still
    applies.
  - Fix: Space (jump) pressed A in vehicles, which is "Exit"; it now stays jump there.
  - Fix: with a frame limit above 60, menu animations ran too fast (scrolling lines, the spinning player model,
    the title's pulsing bomb). Menus, the pause screen and cutscenes now always run at 60 fps; the limit applies
    while you play on foot.
  - Classic PC shooter keys (new defaults; layouts you changed yourself are kept): E use / enter and exit
    vehicles, R reload / ammo type, right mouse sniper zoom, Esc pause, mouse wheel next / previous weapon,
    Q next weapon (hold: weapon wheel), F previous weapon, Space jump (no longer also the right mouse button).
  - Mouse in menus, the pause screen and cutscenes: the wheel moves the selection, left click selects, right click
    goes back. Esc opens and closes the pause menu.
  - Holding fire or jump when a cutscene starts no longer skips it (the button has to be pressed again).
  - Driving with WASD: in vehicles A / D steer (the mouse still steers too); before, only the mouse steered.
  - Weapon wheel with the mouse: hold Q (or whichever key / button you bound to X), move the mouse towards a
    weapon and release to take it. A quick tap still switches to the next weapon.
  - The click that captures the mouse no longer also selects in menus or fires.
  - Number keys pick weapons: 1 chainsaw, 2 Desert Hawk, 3 double shotgun, 4 Uzis / minigun, 5 rocket /
    grenade launcher, 6 Sirian power gun / flamethrower, 7 sniper rifle, 8 cannon, 9 Serious Bomb. Press a
    key again for the other weapon of its pair; weapons you don't have (or have no ammo for) are skipped.
    Rebindable in F12 > Keyboard & Mouse (and to gamepad buttons).
  - Keyboard & mouse button hints: the game's on-screen buttons ("A Select", "Press A to skip", tutorial
    hints) show your keys and mouse buttons while you play with the keyboard and mouse, and switch to Xbox /
    PlayStation buttons when you use a controller (F12 > Gamepad > On-screen buttons: Automatic).
  - Up to three keys / buttons per control. Q and F are next / previous weapon, and X / Y in menus (Add /
    Delete Player), where the mouse buttons and wheel select, go back and scroll.
  - Fix: in-engine cutscenes (GPU renderer) showed a frozen gameplay frame instead of the cutscene.
  - Slightly lower CPU use on the game thread (graphics command and vertex processing).

NEW FEATURES
  Save states
    - Save anywhere with F5 and come back to that exact moment with F9. Five slots (Shift+F5 picks the next one);
      F12 > Save states shows each slot with a picture and the date, with Save / Load buttons.
    - Loading a state also restores the memory card as it was at that moment (the card from before loading is
      kept as a .bak file next to it). States work from the main menu on, not on the boot screens.
  PAL / Europe version
    - Serious Sam: Next Encounter for Europe (G3BP9G; English, French, German) is supported alongside the USA
      release, with everything listed here. Each region has its own memory card file.
  Graphics
    - Anti-aliasing (F12 > Graphics): FXAA, MSAA 2x / 4x / 8x, or supersampling.
    - Anisotropic filtering 2x - 16x: floors and walls stay sharp at steep angles.
  Controllers
    - Rumble on Xbox, PlayStation, Switch Pro and most other gamepads, with a strength slider and a Test button.
    - New default gamepad layout (Xbox style): A jump, X use, B back, RT fire, LB / RB switch weapons,
      Y = the GameCube's Z, Start pause. "GameCube layout" in F12 > Gamepad restores the original positions.
    - The game's on-screen button hints ("A Select", "Press A to skip", in-game tips) show Xbox or PlayStation
      buttons to match your controller and your bindings (F12 > Gamepad > On-screen buttons).
    - Mouse wheel can be bound to any control; by default it switches weapons.
  Convenience
    - Skip intros (on by default): the game starts at the main menu in about 10 seconds instead of ~50.
    - Pause in the background (on by default): Alt+Tab or minimizing pauses and silences the game.
    - "Exit game" button in the F12 menu.
    - Short on-screen messages for save states, screenshots and volume changes.
    - Graphics presets (F12 > Graphics): Low / Medium / High / Ultra in one click.
    - Separate volume for music & videos and for sound effects (F12 > Audio).
    - Monitor choice for fullscreen; the window remembers its size, position and maximized state.
    - Screenshots: Print Screen (or Shift+F12) saves a PNG of the game image to the Screenshots folder.
    - Info bar: full, frame rate only, or hidden (Shift+F1 cycles).

FIXES
  - Jumping: Space never jumped. The game jumps with the GameCube's (analog) L trigger and the old default put
    Space on A. Space now jumps and still selects in menus and skips cutscenes. Existing settings that were never
    changed are updated automatically.
  - Stick flicker: holding either stick (or A+S on the keyboard) down-left made Sam stop or jitter. The game
    rescaled the stick values in place, and at PC frame rates did it more than once per controller read, which
    flipped down-left to up-right. Each frame now sees the raw input, as on the GameCube.
  - Exiting (Alt+F4 or the window's X): the window is closed before anything else and the game is forced to
    end if shutting down stalls (reports of the desktop staying dimmed after quitting).
  - Automatic resolution now also lowers the resolution when the game runs below 20 fps (it never did there).
  - Clearer key labels in F12 (A is select / use / skip, L is jump, X / Y switch weapons).

PERFORMANCE (mainly for weaker PCs)
  - Automatic internal resolution (new default): starts at the resolution that fits the window and lowers or
    raises it from the measured GPU time. Old settings with the previous fixed 3x move to automatic.
  - Much less GPU work per frame: depth writes only where needed (early depth test works again), fewer state
    changes and uniform uploads, EFB copies converted in one pass instead of two.
  - Shader cache (shadercache folder): no more stutter the first time an effect appears, after the first session.
  - Lower CPU use: faster vertex decoding, no busy-waiting main loop, frame buffers reused.
  - Sync game to display (on by default): with vsync and a 60 Hz screen the game ticks with the display, so no
    frame is shown twice (removes a periodic micro-stutter).

COMPATIBILITY
  - Windows 7 SP1 and 8.1 (64-bit) are supported, as well as 10 and 11. Everything now uses the C runtime that
    every Windows version includes; the launcher downloads the matching compiler once (about 146 MB).
  - Windows 7: the compiler download asks for TLS 1.2 (install the KB3140245 update if it still fails, or
    download the file named in the error with a browser and put it in build-kit\downloads).
  - The launcher offers "Update Game" automatically whenever a release changes the engine.

CHANGED KEYS
  F5 ............ save state (was volume up)        F9 ........... load state (was frame capture)
  Shift+F5 ...... next save state slot              F4 / Shift+F4  volume down / up
  Shift+F9 ...... capture a frame for bug reports    Print Screen / Shift+F12  screenshot
  Shift+F1 ...... info bar: full / frame rate only / hidden
  Keyboard: Space = jump (L), F = A (use / select), right mouse = jump, mouse wheel = switch weapons.
  Gamepad: Xbox layout by default (see above).
